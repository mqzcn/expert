Expert Language is a platform that connects interpreters and translators to client who need these services.

It's built with the MERN (MongoDB, Express, ReactJS, NodeJS) stack, and code for both api and frontend lives in this repo.

## Getting Started

To setup for local development, follow these steps:

1. Clone the repo

2. Navigate to /api

3. Run the start command

4. In a separate terminal navigate to /frontend

5. Run the start command

6. Open localhost in a browser window with the revelant port
